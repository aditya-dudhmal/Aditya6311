## Featured projects

**[heart-disease-ml](https://github.com/Aditya6311/heart-disease-ml)** —
End-to-end classification pipeline on clinical patient data.
Compared logistic regression, random forest, and XGBoost with 5-fold
cross-validation — best test ROC-AUC **0.950**.
`Python · pandas · scikit-learn · XGBoost · seaborn`

**[drug-review-nlp](https://github.com/Aditya6311/drug-review-nlp)** —
NLP sentiment classification on **215k patient drug reviews**.
TF-IDF (unigrams + bigrams) with logistic regression vs Naive Bayes —
ROC-AUC **0.935**, and a per-class analysis of which patients each
model misses. `Python · NLP · TF-IDF · scikit-learn`

**[demand-forecasting](https://github.com/Aditya6311/demand-forecasting)** —
Time-series demand forecasting: seasonal decomposition, ADF
stationarity testing, SARIMA vs random forest vs seasonal-naive
baseline — SARIMA holdout MAPE **3.7%** vs 10.0% baseline.
`Python · statsmodels · SARIMA · pandas`

**[heart-risk-dashboard](https://github.com/Aditya6311/heart-risk-dashboard)** —
Streamlit dashboard for exploring heart disease risk patterns,
framed for a clinic-team audience. `Streamlit · pandas · matplotlib`
